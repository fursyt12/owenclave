# 0.20.9

- Add full cross-platform Desktop client (Linux, macOS, Windows) sharing the Android Material 3 Expressive 7-tab Compose UI (`Configuration`, `Groups`, `Route`, `Settings`, `Logcat`, `Traffic`, `Tools`), protocol stack and Go core (`owenclave-core`, `libgojni`, `naive`, `tun2socks`)
- Add privileged Desktop VPN (TUN) mode on Linux via Polkit (`pkexec`) and `owenclave-tun-helper` with conflict-free subnet selection, DNS hijack/IPv6 leak protection, and automatic stale system-proxy cleanup
- Add desktop URL scheme registration and single-instance deep-link forwarding for `owenclave://`, `owenkey://`, `happ://`, `clash://`, `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `tuic://`, `anytls://`, `wireguard://` and `socks://`
- Add HTTP and HTTPS proxy creation UI and `http://` / `https://` share-link round-trip support on Android and Desktop
- Add headless Mihomo-compatible REST daemon and built-in Web UI (`/ui/`) for Docker deployments
- Fix multi-outbound NaiveProxy routing, `Owenclave/<version>` subscription `User-Agent`, session log rotation, and headless CI test reliability across Linux, Windows and macOS
