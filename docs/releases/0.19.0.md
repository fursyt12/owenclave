## Owenclave 0.19.0 (Pre-release)

### Desktop (Windows, Linux, macOS) — 1-to-1 Android Architecture & Native Core
- **1-to-1 Android UI & Backend**: Desktop now compiles the Android Material 3 Expressive Compose UI (`ConfigurationScreen`, `SettingsScreen`, `RouteScreen`, `RouteSettingsScreen`, `GroupScreen`, `LogcatScreen`, `TrafficScreen`, `ToolsScreen`, `AboutScreen`, `StunScreen`, `ProbeCertScreen`, `ScannerScreen`) and backend packages (`fmt`, `database`, `group`, `bg`, `ktx`, `utils`) directly from `app/src/main/java`.
- **Native `libexclavecore` Go Core (JNI + CLI)**: Built from `github.com/exclavenetwork/libexclavecore` via `gobind` as native `libgojni.so` (Linux), `gojni.dll` (Windows), and `libgojni.dylib` (macOS) alongside `owenclave-core(.exe)`.
- **Native Windows Launcher (`Owenclave.exe` / `owenclave.exe`)**: Self-contained portable Windows x64 build with embedded JRE 21 (`runtime/`) and native executables (`Owenclave.exe` and `owenclave.exe`) with zero external MinGW DLL dependencies.
- **Full NaiveProxy Support**: Bundled `naive` (`154.0.8037.49-5`) plugin discovery, startup port readiness check, and automatic OS system proxy management on connection/disconnection.

### Upstream Sync (`v0.18.0`)
- Added **MASQUE** (`MASQUEBean`) protocol support.
- Updated **ShadowQUIC** (`SunnyQUIC` / `ShadowQUIC` sub-protocols), **NaiveProxy**, and **StandardV2RayBean** mux settings.
- Removed deprecated `OLCRTC` protocol.
- Updated `libexclavecore` and `exclave-core` to `v5.50.1`.
